#Student Management System
A console-based Student Management System built in C++.

---------FEATURE------------
Add student
Display all students
Search student by roll number
Update student details
Delete student
Duplicate roll number validation
Age and marks validation
File handling
Data persistence

--------TECHNOLOGIES USED-------

C++
STL Vector
Structures
Functions
File Handling
Control Flow


--------HOW TO RUN--------
Clone the repository.
Open the project in a C++ IDE or VS Code.
Compile main.cpp.
Run the program.


--------LEARNING OUTCOMES--------

This project helped me practice C++ fundamentals, STL vectors, functions, file handling, CRUD operations, input validation, and Git/GitHub workflow.
